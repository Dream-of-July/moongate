## Known Release Limits

- Builds are ad-hoc / unsigned for local QA only.
- Apple notarization is intentionally not done.
- Windows real-hardware QA is not done; current validation is macOS-hosted .NET plus Parallels Windows 11 VM.
- Local ASR real-runtime QA requires user-provided `whisper-cli`, model, ffmpeg, and a local sample; normal CI/preflight does not download any runtime or model.

## Smoke Path

1. Open the app and confirm Settings opens as a separate window.
2. In Settings, confirm General, Subtitles & Translation, Local Speech Recognition, AI Services, Video & Output, Site Login, Components & Storage, and Updates & About panes are visible.
3. In Site Login, confirm "Clear this app's login data" is destructive/red and has confirmation.
4. In Updates & About, confirm the About section has one GitHub repository button and the version appears only in the update section.
5. Parse a video with platform/manual subtitles.
6. On the ready page, choose exactly one subtitle source and one subtitle output mode.
7. Start a normal non-ASR download and confirm progress starts as download progress rather than jumping ahead to later phases.
8. Parse a video with no usable subtitles; if local ASR is configured and ready, confirm Local Speech Recognition appears as a subtitle source.
9. For a completed download, use the queue waveform action to rerun local speech recognition, translation, and burn-in without re-downloading the video.
10. Download a 2160p/4K-capable video and confirm the selected 4K format is not silently constrained to 1080p.
11. Run a burn-in job and compare output size against source; large blow-ups should no longer happen on ordinary known-bitrate sources.
12. Let a batch finish and confirm completion notification and sound follow the app settings.

## API Translation Path

2. Choose a non-local translation provider in onboarding.

## Local ASR Settings Path

1. Open Settings > Local Speech Recognition.
2. Confirm the model list shows concise model size and capability text.
3. Confirm an installed model can be selected with "Use" and then shows "In use".
4. Confirm runtime path, model path, and model ID fields are behind Advanced.
5. Confirm model download is explicit; the app should not auto-download a runtime or model.

## Branch `ui-ux-overhaul` — New Feature QA

Manual QA steps for the features added on this branch (not in v0.8.0). Automated
coverage: macOS `swift test` (720) + Windows `dotnet test` (806) all green; these
steps cover the GUI/rendering behavior tests cannot assert. Nothing here changes
defaults — every new subtitle setting defaults to the previous behavior
(standard size / bottom / white), so an untouched install must look identical to
before.

### Bundle smoke (run first, catches packaging regressions)
0. After `./build.sh`, confirm the installed app actually launches:
   `open -a "/Applications/月之门.app"` → main window appears, no crash. If it
   crashes on launch, check `~/Library/Logs/DiagnosticReports/Moongate-*.ips` for
   a `Library not loaded: @rpath/Sparkle.framework` (missing framework) or a
   codesign error — build.sh copies Sparkle into `Contents/Frameworks/` and
   ad-hoc signs, so a dyld/Sparkle failure means the bundle step regressed.
   (build.sh itself does not launch-verify; this is the manual gate.)


### Subtitle appearance (size / position / color) + live preview
1. Settings > Subtitles & Translation, subtitle style section. Confirm three new
   pickers: 字幕大小 (小/标准/大/特大), 字幕位置 (底部/顶部), 字幕颜色 (白色/黄色).
2. Confirm a 16:9 dark preview card sits below them and updates live as each
   picker changes: size scales the sample text, position moves it top/bottom,
   color switches white↔yellow (both bilingual lines change color together).
3. Burn a bilingual subtitle with 大 + 顶部 + 黄色; confirm the burned video shows
   larger yellow subtitles anchored at the top, black outline intact.
4. Set everything back to 标准/底部/白色, burn again; confirm output matches the
   pre-branch look (regression check — defaults unchanged).
5. Edge: burn a video whose SRT is unusual/empty-parse (fallback path) with a
   non-default appearance; confirm size/position/color still apply (not a
   hardcoded 15pt/white/bottom). Cross-platform: repeat one appearance combo on
   Windows with the same settings.json and confirm the burn matches macOS intent
   (note: base font size differs 13 vs 15 between platforms — a known, documented
   item, see exec-plan; not a QA failure).

### Ready-page deep link
6. On the ready page, choose a burn-in subtitle output mode; confirm a
   "调整字幕大小、位置与颜色" link appears and, when clicked, opens Settings
   directly on the Subtitles pane. Choose an SRT-only (non-burn) mode; confirm the
   link is hidden (appearance is irrelevant without burn-in).

### Keyboard shortcuts
7. Cmd+L focuses the URL field (like a browser address bar). Cmd+Shift+V pastes
   the clipboard and parses. Cmd+, still opens Settings. Confirm the File menu
   lists "新建下载" and "粘贴并解析".

### Empty / loading / failed / onboarding states
8. Launch with an empty queue; confirm the empty state shows a hierarchical icon,
   a strong title, a secondary subtitle, and a restrained "supported platforms"
   line, with a gentle fade-in (and no animation under Reduce Motion).
9. Trigger a parse failure (bad URL); confirm the failed state is legible with a
   recovery action. Trigger the loading state; confirm a clear progress + cancel.
10. Reset onboarding (QA only); confirm the step indicator clearly marks current
    (filled/accent), completed (checkmark), and upcoming (dimmed) steps.

### Three-pane prototype (default OFF — must not affect normal use)
11. Confirm normal launch shows the existing single-column UI (flag off).
12. Enable preview: `defaults write com.moongate.app experimental.splitLayout -bool YES`,
    relaunch. Confirm a Notes-style two-pane: left sidebar lists videos grouped
    "进行中 / 已完成" with a progress ring (partial ring while downloading), right
    detail shows a 16:9 preview (play overlay when done → opens in default player),
    title/meta, live status text matching the legacy queue, and stage-aware action
    buttons (pause/resume/cancel/retry/reveal/remove).
13. In split mode, click "+" → paste one or more links → Add; confirm tasks
    auto-enqueue at best quality and appear live under 进行中.
14. Disable: `defaults write com.moongate.app experimental.splitLayout -bool NO`,
    relaunch; confirm back to the normal UI with no residue.

### Language-tag correctness (R4/R29)
15. Run local ASR on a Chinese-audio video that a platform mislabels as English;
    confirm the produced `.local-asr.<lang>.srt` is named `zh-Hans` (content-based),
    not `en`. (Pre-existing already-produced files are intentionally not renamed.)
