# 月之门 0.9.2：下载优先的简化工作台

## 背景与产品意图

0.9.1 已建立资料库、待开始任务和工作台，但把下载、处理配置、组件诊断和资料库信息同时放在主界面，导致结构和文案复杂。0.9.2 的首要目标是让用户默认只需“粘贴链接 → 入队 → 使用视频”，并在需要时才暴露字幕、重处理与本地识别能力。

## 当前实现

- `LibraryWorkspaceView` 使用三列 `NavigationSplitView`，但中栏仍手工绘制标题和新增按钮，详情内部又以 `HStack` 追加 Inspector。
- `RootNewDownloadSheet` 在一个 disclosure 中暴露画质、来源、模型、翻译和样式。
- `PreparationCenterView` 直接展示底层 runtime、模型、路径和组件目录。
- `LibraryProjection` 会在实时队列更新时重建排序结果；`ProcessingSummary` 没有持久化的异常恢复语义。

## 目标与非目标

目标：真正三层工作台、默认收起的系统 Inspector、下载优先 Sheet、按需能力准备、具体异常恢复、稳定列表投影和可验证的 macOS 测试包。

非目标：重做 Windows UI、引入新的 ASR 引擎、修改既有用户的下载默认值、在无法完整安装 runtime 时承诺一键启用本地识别。

## 里程碑

1. 将资料库 schema 升至 v2，并持久化安全的 `ProcessingAttention`。
2. 使用 SwiftUI `.inspector` 移除详情内部伪第四列；把新增下载移入中栏 Toolbar。
3. 将处理配置迁移到“更改选项”与“重新处理”Sheet，Inspector 只显示信息。
4. 删除常规准备中心路径，改为结果导向的本地识别能力 Sheet，并简化 Settings/Onboarding。
5. 分离资料投影和活动任务覆盖层，增加缩略图缓存与性能测试。
6. 跑完整测试、构建、真实 App Computer Use 验证和 DMG 打包。

## 风险与回滚

- `libraryWorkspace.enabled` feature flag 在一个测试版本内保留，legacy 下载界面可回退。
- schema v1 迁移只增加可选异常信息，不丢弃资料或产物；未知旧异常显示“需要重新检查”。
- 本地识别只在完整组件链真实可用时显示“一键准备”；否则保持可操作的下载/平台字幕/云端回退。

## 验证清单

- 资料库 schema、异常恢复、队列快照和重新处理单元测试。
- 新建下载、待开始编辑、完成、失败恢复、重处理、Onboarding 和设置 UI 边界测试。
- 1000 条资料与四任务状态下的投影/滚动性能基线。
- 浅深色、减弱动态效果、VoiceOver、键盘、900/1100/1440pt 和 AVKit 媒体手动测试。
