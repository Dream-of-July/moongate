# Moongate 0.9 — macOS 视频资料库 + 工作台 ExecPlan

分支：`codex/v0.9-library-workspace`（从 `ui-ux-overhaul`）  
开始：2026-07-11  
授权：七月已明确要求先实现本地可测试 App/DMG；Figma 同步延后至实际版本试用通过后。

## 1. 背景与产品意图

0.8 的 `SplitLayoutView` 是可用的 queue-first 原型，但终态任务随内存队列消失，不能承担“视频资料库”的稳定信息架构。0.9 将其升级为 macOS 优先的三层工作台：状态/标签侧栏 → 视频与任务列表 → 视频工作台；Inspector 是工作台内可折叠面板，不新增固定第四列。

用户这轮优先验证真实可运行体验，而非先评审静态 Figma。因此本分支交付一个本机 `0.9.0 (9001)` 测试 DMG；不改公开 appcast、Windows UI 或正式发版面。

## 2. 已确认的仓库事实

- `QueueManager.QueueItem`（`Sources/Moongate/QueueManager.swift`）含 `AppSettings`、`TaskControlToken`、`Task` 和实时进度；不能持久化，更不能写入 token、Cookie、API key。
- `QueueManager` 是唯一实时任务控制器；入队时立刻启动 pipeline，重试会复用同一 ID/产物，均不符合资料库版本语义。
- `ContentView` 把 onboarding、依赖、登录、设置窗口驱动和 source-language sheet 绑定在 legacy 分支；当前 experimental split layout 不可直接设为默认。
- `AppSettings` 已提供 Application Support、原子 replace、0600 和损坏备份模式，可作为 LibraryStore 实现参考，不能把整个 `AppSettings` 写进资料库。
- 基线：2026-07-11 `swift test` 799 tests passed；当前 0.9 改动后的全量验证为 834 tests passed。

## 3. 目标与非目标

### 目标

1. 持久化安全资料库：`library.json`、稳定 ID、相对产物路径、0600、原子写、损坏备份、schema 迁移和只读恢复扫描。
2. 将每次入队同步为同一资料记录；Queue 只覆盖实时状态，完成/部分成功/失败更新同一条记录且不产生重复项。
3. macOS 三层资料库工作台：1440/1100/900 宽度规则、可隐藏侧栏/Inspector、真实新建下载、列表搜索与状态过滤。
4. AVKit 内嵌 MP4/MOV/M4V；不支持格式显示“使用默认 App 打开”。
5. 信息/处理 Inspector，运行中只读；完成项修改生成变更摘要并创建新版本重新处理任务。
6. 初次启动恢复扫描、异常退出标为已中断、索引移除可撤销、废纸篓独立确认。
7. legacy feature flag 保留一个测试版本，0.9 测试包默认展示新工作台。

### 非目标

- 逐句字幕、时间码、时间轴编辑（推迟到 0.9.1）。
- Windows 0.9 UI 重做或公开正式 release 面升级。
- 自动承诺跨启动下载续传。
- 重写已有下载/字幕/翻译算法。

## 4. 架构与数据边界

### Core（平台中立）

新增 `Sources/MoongateCore/LibraryModels.swift`、`LibraryStore.swift`、`LibraryProjection.swift`、`ReprocessPlanner.swift`、`ReprocessWorkspace.swift`：

- `LibraryEnvelope(schemaVersion, tags, items)`；`LibraryItem`、`LibraryVersion`、`LibraryArtifact(role, relativePath, size, modifiedAt)`、`ProcessingSummary`。
- 只保存白名单：标题、来源描述（移除 URL query/fragment/userinfo）、标签、置顶、备注、时间、产物相对路径、状态、实际模型名、无凭据的处理快照。
- `LibraryStore` actor 串行读写。写入到 `Application Support/月之门/library.json`，临时文件 replace、0600、损坏备份与 schema migration。
- `LibraryProjection` 为纯函数：状态/标签过滤、搜索、置顶→活动→最近排序，以及活跃 Queue 覆盖。
- `ReprocessPlanner` 为纯函数：仅字幕样式→burn；翻译语言/模型→translate+downstream；ASR 模型/字幕来源→ASR+downstream；本地格式改动→transcode；画质或恢复源格式→refresh source。
- `ReprocessWorkspace` 在 `.moongate-versions/vN-*` 创建隔离目录并复制产物；旧版本永不被新处理任务覆盖。

### App（macOS）

- `LibraryWorkspaceModel` 与 `QueueLibrarySnapshot` 从 QueueItem 构造安全 `ProcessingSummary`，新任务立即落库，进度 tick 经过防抖后更新投影与持久化状态。
- Queue job 获得 `libraryItemID`/`outputVersionID`，原任务和重新处理新版本互不覆盖。
- `ContentView` 根级持有 `LibraryWorkspaceModel` 和共用 lifecycle/Sheet；`AppRootHost` 承载可用的多链接新建下载 Sheet；layout selector 可切换 `LibraryWorkspaceView` 与 legacy。
- `LibraryWorkspaceView` 使用三列 `NavigationSplitView`：sidebar（状态+tag）→ content（库/任务列表）→ detail（播放器+工作台）。Inspector 在 detail 内展开，不成为第四列。

## 7. 风险、回滚与决策

- 资料库绝不存 `AppSettings`、token、Cookie、完整 URL 凭据；用安全投影隔离。
- 入队立即运行的现状与“排队可编辑”冲突；必须让 Queue 在真正执行前固化运行快照。
- AVKit 不支持 MKV/WebM 时必须显式外部打开；不伪造内嵌播放能力。
- feature flag `libraryWorkspace.enabled` 保留 legacy 回退；测试包默认 on。
- 如新 UI 未通过用户试用，可开 legacy，不损坏既有下载/产物。
- “使用默认”输出格式按 `.original` 规划，避免把旧 H.264/H.265 复制成伪新版本；画质/源格式刷新时只携带可复用字幕 sidecar。
- “移到废纸篓”不会显示索引级撤销；只有“从资料库移除”保留可撤销语义。

## 10. 0.9.1 工作台与准备中心修订

授权：七月已在 2026-07-11 确认本节方案，目标是优先交付本地可试用的 `0.9.1` 测试 DMG，Figma 同步继续延后。

### 已锁定的产品决策

- 新链接创建为可编辑的“待开始”任务；用户可逐项调整，再启动单项或全部。
- Inspector 收起后按状态显示紧凑操作；不重复播放器的播放控制。
- 本地 ASR runtime 改为按需下载；模型/VAD 仍独立管理。
- 默认“删除”只移除资料库索引并支持撤销；废纸篓是独立、确认后的破坏性操作。
- 组件安装从设置偏好中抽离为共享的准备中心；onboarding 与设置进入同一状态面。
